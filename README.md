# Gestione Tavoli & Planimetria

Apri `index.html` nel browser.

## Funzioni
- Logo permanente (carica/rimuovi)
- Aggiungi/elimina planimetrie e eventi
- Carica lista ospiti: PDF, Word, Excel, foto (OCR), copia-incolla
- Distribuzione equa (famiglie per cognome)
- Scarica PDF = lista ospiti + planimetria
